# Технологии

Стек отдельно не обсуждали. Он следует из решений 1 и 5: одна страница по QR-коду, сервер не нужен, ничего не сохраняется. Первая версия сделана так 27.10.2026.

- Один статический файл `index.html` в корне проекта: разметка, стили и скрипт внутри, без сборки и зависимостей.
- Вопросы хранятся массивом `QUESTIONS` внутри страницы. Порядок вопросов фиксированный.
- При загрузке страница проверяет вопросы (`console.assert`): у каждого 3–4 варианта, правильный ответ существует, есть ссылка на источник.
- Вёрстка под телефон в стиле презентаций интенсива (`C:\Vibe Projects (Pet)\INTENSIV LICENSE\presentations\lessonNN\src\style.css`, тёмная тема). Живой фон — `field.js`, скопирован из урока 5 без изменений (частицы-нити, реагируют на касание, при `prefers-reduced-motion` неподвижны). Карточки полупрозрачные `rgba(46,40,40,.86)` без размытия. Заголовки Unbounded 600 капсом, текст Inter Tight (оба с Google Fonts), акцент `#4d61f4`. Навык `artbrodsky-style` к интенсиву не относится.
- Локальный просмотр: `python -m http.server 8765` (`.claude/launch.json`). Без сервера `field.js` во встроенном браузере не подгружается.
- Хостинг: GitHub Pages из репозитория https://github.com/nakarandashe27/tower-quiz, ветка `main`, корень. Адрес: https://nakarandashe27.github.io/tower-quiz/. Решение пользователя от 27.10.2026.
- QR-код: файл `qr.svg` в корне проекта, ведёт на адрес из Pages. Сделан Python-библиотекой `qrcode`. Если поменяется адрес, QR-код нужно сделать заново.

Пересмотреть, если появятся другие языки, банк вопросов или сохранение результатов.
