# Правила, которые НИКОГДА не должны нарушаться

## Базовые
- Ни одного факта вне [пула фактов](пул-фактов.md). Ничего не додумываем, в том числе в пояснениях и неверных вариантах ответа.
- Неверный вариант ответа не должен случайно оказаться верным по другому источнику. Например, не ставим 1859–1863 неверным ответом на вопрос о годах постройки башни: реестр даёт эти годы для башни вместе с машинным отделением и котельной.
- У каждого вопроса есть ссылка на источник.
- Никаких персональных данных и сохранения состояния.

## Правила проекта
- Пишем «архитектор Шуберский, проект составлял его помощник Мерц», а не «архитектор Мерц» и не «архитектор Шуберский» без оговорки.
- Годы постройки башни — 1859–1861, годы постройки станции — 1858–1863. Не путаем их.
