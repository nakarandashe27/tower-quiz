# Аудитория

Взрослые посетители музейного комплекса и прохожие, которым интересна архитектура и история города. Викторину проходят на месте, у башни или в музее, со своего телефона.

Что это значит для вопросов:
- можно спрашивать о тонкостях, например «по должности архитектор Шуберский, а проект составлял его помощник Мерц»;
- тон спокойный, без детских формулировок;
- викторина должна проходиться за 2–3 минуты, стоя.

Сегменты, точный тон и запрещённые слова не обсуждали: [заполнить позже].
