# Викторина «Водонапорная башня на Шпалерной, 56»

Короткая викторина для посетителей водонапорной башни на Шпалерной, 56 в Петербурге. Посетитель открывает её со своего телефона по QR-коду. Учебный, некоммерческий проект.

Собрано 27.10.2026 в ускоренном режиме context-builder: только этапы «идея» и «устройство». Этап «бизнес» пропущен, потому что проект некоммерческий.

## Навигация

| Папка / файл | Что там |
| --- | --- |
| [idea/](idea/README.md) | Замысел: зачем, для кого, что входит в первую версию |
| [architecture/](architecture/README.md) | Устройство: границы, данные, стек |
| [открытые-вопросы.md](открытые-вопросы.md) | Допущения и то, что не выяснили |

## Ключевые файлы

- [idea/01-idea/README.md](idea/01-idea/README.md): идея одним предложением и шесть решений интервью.
- [idea/03-audience/README.md](idea/03-audience/README.md): для кого викторина.
- [idea/04-mvp/scope.md](idea/04-mvp/scope.md): что входит в первую версию и что сознательно не входит.
- [architecture/01-обзор/границы.md](architecture/01-обзор/границы.md): что делает система и что остаётся снаружи.
- [architecture/03-данные/пул-фактов.md](architecture/03-данные/пул-фактов.md): **единственный источник фактов для вопросов**, со ссылками.
- [architecture/03-данные/правила-нерушимые.md](architecture/03-данные/правила-нерушимые.md): правила, которые нельзя нарушать.
- [architecture/05-стек/технологии.md](architecture/05-стек/технологии.md): стек — один `index.html`.

Первая версия: `../index.html`, 7 вопросов. Каждый вопрос построен на факте из пула.

Исходники фактов лежат в `../sources/`. Их не редактируем: новый факт сначала добавляется в справку, потом в пул.

**Правило:** при работе читай только нужный файл, не загружай всё сразу.
